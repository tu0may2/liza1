ЕСЛИ MAC ПИШЕТ «ФАЙЛ НЕ БЫЛ ОТКРЫТ»
====================================

Вы увидели окно с жёлтым треугольником:

    «Файл "start.command" не был открыт.
     Apple не удалось подтвердить, что файл не содержит
     вредоносного ПО...»

Это нормально и не значит, что с файлом что-то не так.

Так macOS поступает с ЛЮБЫМ скачанным из интернета файлом, который не
подписан платным сертификатом разработчика Apple. Система не проверяла
содержимое — она просто не знает, кто автор.

ВАЖНО: нажмите «Готово». НЕ НАЖИМАЙТЕ «Переместить в Корзину» —
иначе платформа удалится.


КАК ЗАПУСТИТЬ — СПОСОБ 1 (одна команда, потом работает двойным щелчком)
-----------------------------------------------------------------------

1. Откройте Терминал:
   нажмите Cmd + Пробел, наберите «Терминал», нажмите Enter.

2. Наберите вот это, НО НЕ НАЖИМАЙТЕ ENTER (в конце нужен пробел):

       xattr -dr com.apple.quarantine 

3. Перетащите мышью папку с платформой прямо в окно Терминала.
   Путь к ней подставится сам.

4. Теперь нажмите Enter.

Готово. Больше окно с треугольником не появится: двойной щелчок по
start.command будет запускать платформу как обычно.


КАК ЗАПУСТИТЬ — СПОСОБ 2 (без Терминала, через настройки)
----------------------------------------------------------

1. В окне с треугольником нажмите «Готово».

2. Откройте: Системные настройки → Конфиденциальность и безопасность.

3. Пролистайте вниз. Там будет строка про start.command
   и кнопка «Подтвердить вход» или «Открыть всё равно» — нажмите её.

4. Снова дважды щёлкните start.command и подтвердите «Открыть».


КАК ЗАПУСТИТЬ — СПОСОБ 3 (работает всегда, без всяких разрешений)
------------------------------------------------------------------

1. Откройте Терминал (Cmd + Пробел → «Терминал»).

2. Наберите, НЕ НАЖИМАЯ ENTER (в конце пробел):

       python3 

3. Перетащите в окно Терминала файл server.py из папки платформы.

4. Нажмите Enter.

Платформа запустится и сама откроет браузер. Этот способ ничего не
меняет в системе, но повторять его придётся при каждом запуске.


ЕСЛИ НЕТ PYTHON
---------------

Терминал может ответить «command not found: python3».
Тогда скачайте Python с https://www.python.org/downloads/ ,
установите и повторите запуск.


ПОЧЕМУ НЕЛЬЗЯ СДЕЛАТЬ, ЧТОБЫ ОКНА НЕ БЫЛО
------------------------------------------

Чтобы macOS пускала файл без вопросов, его нужно подписать сертификатом
разработчика Apple — это платная годовая подписка, оформленная на
конкретного человека или компанию. Без неё система будет спрашивать про
любой скачанный скрипт, чей бы он ни был.

Команда из способа 1 снимает пометку «скачано из интернета» с вашей
копии платформы — ровно с неё, и ни с чего больше.
